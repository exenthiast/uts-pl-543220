# UTS Praktikum Rekayasa Perangkat Lunak - 543220

Repositori implementasi sistem berbasis RESTful API Laravel 13, Frontend Vue.js 3, Docker Multi-stage + FrankenPHP, dan GitHub Actions CI/CD.

## Struktur Direktori
- `backend/`: RESTful API Laravel 13 + Sanctum + FrankenPHP
- `frontend/`: Vue.js 3 SPA (Vite + Pinia + Axios)
- `postman/`: Postman Collection JSON
- `.github/workflows/`: GitHub Actions CI/CD Pipeline
- `docker-compose.yml`: Orkestrasi Docker container (Database, Backend, Frontend)
